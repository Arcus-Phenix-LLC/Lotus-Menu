A familiar menu. Your own tools.

Place tools in Directory beside Lotus Menu.exe. Nested folders become categories. A folder containing an executable becomes a tool; its supporting folders stay hidden.

If several executables are found, choose the main one below the menu. Lotus saves your choice in that folder’s lotus.json.

Restart Lotus or use Refresh Menu after changing tools. This version launches Windows .exe files. Tools requiring administrator access must be started from an elevated Lotus instance.

The default theme recalls Windows Vista/7. More themes are planned.
